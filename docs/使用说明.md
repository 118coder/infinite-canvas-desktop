# 无限画布 使用说明

这是一份面向使用者的快速上手文档，压缩包里除了本文件，还有 `infinite-canvas-desktop.exe`、`LICENSE` 和 `VERSION`。

## 一、运行环境

- Windows 10 / 11（x64）
- 需要系统自带或已安装 **WebView2 运行时**（Win11 自带；Win10 若打不开窗口，装一下微软官方的 "Microsoft Edge WebView2 Runtime" 即可）

## 二、第一次打开

1. 把压缩包解压到一个**有写权限**的目录，例如 `D:\软件\无限画布\`，**不要放在 `C:\Program Files`**；
2. 双击 `infinite-canvas-desktop.exe`；
3. 首次启动会在 exe 同级生成 `userdata\` 目录，画布数据、生成的图片、网页缓存全部存在这里，卸载时删掉整个文件夹即可，不会往 C 盘塞东西。

> 程序会在 `127.0.0.1` 上起一个本地服务（默认端口 36512），端口号记在 `desktop-port.txt`。
> **这个端口就是本地数据的"身份"**，每次启动会尽量复用同一个端口，请不要随手删除或修改它，否则会读不到原来的画布。

## 三、配置模型渠道（必做）

1. 点右上角齿轮打开「设置」；
2. 在「渠道模式」里选择或新增一个本地渠道，填入：
   - **Base URL**：例如 `https://api.xxx.com/v1`（OpenAI 兼容接口）
   - **API Key**：你的密钥
   - **模型**：填你要用的图片 / 视频 / 文本模型名
3. 保存后回到画布即可开始生成。

所有配置都只存在本机，不会上传到任何服务器。

## 四、基本用法

| 想做的事 | 怎么做 |
| --- | --- |
| 新建画布 | 画布列表页点「新建」 |
| 加图片 | 直接把图片拖进画布，或双击空白处新建节点 |
| 让一张图当参考 | 把参考节点连到目标节点上；或点目标节点「参考内容」里的 `+` 选择节点 |
| 提示词里引用某张图 | 输入 `@` 选择，或**直接点「参考内容」里的缩略图**，会自动插入 `@图片N` |
| 生成 / 重新生成 | 选中节点，在下方提示词框输入内容，回车或点右下角按钮；再次点生成会**在原节点上重新生成** |
| 保留旧结果再生成 | 选中节点按 `Ctrl / Cmd + D` 创造副本，在副本上改提示词 |
| 存素材 | 右键图片节点 →「存素材」，之后在「我的素材」里复用 |
| 撤销 / 重做 | `Ctrl + Z` / `Ctrl + Shift + Z` |

## 五、数据迁移到另一台电脑

设置 → 数据工程，有两种导出方式：

- **完整包**：把画布、素材、配置和所有图片本体打成一个 zip，体积大，换台电脑导入后直接接着用；
- **引用包**：只导出画布结构和每张图片的 `storageKey / MD5 / 文件名` 清单，体积几百 KB，适合先同步结构。

导入引用包时，软件会检查每张图在本机是否已存在，缺失的会列在「缺失图片补齐」里：点「选择文件」或「批量定位文件」，按 MD5 / 文件名 / 大小自动匹配，补齐后画布自动恢复。

## 六、常见问题

**双击没反应 / 白屏**
装一下 WebView2 运行时；或确认 exe 所在目录有写权限（程序要在这里建 `userdata`）。

**重启后画布列表空了**
端口变了。检查 `desktop-port.txt` 是否被删，或被别的程序占用，换回原端口再启动。

**节点一直显示「生成中」**
如果是生成途中关过软件，重开后会变成可重试的失败态，点「重新生成」即可。渠道后台若已出图，可以到后台下载原图。

**图片显示「图片缺失」**
本地图片文件丢了（清过 `userdata` 或导入的是引用包）。到设置 → 数据工程里补齐。

**C 盘被占用**
新版数据都在 exe 同级的 `userdata` 里。若从旧版升级，可手动删除 `C:\Users\<你>\AppData\Roaming\infinite-canvas-desktop.exe` 这个旧目录。

## 七、卸载

关闭程序 → 删除整个文件夹（包含 `userdata`、`desktop-port.txt`、`data`）即可，不会在系统里留下其他东西。
