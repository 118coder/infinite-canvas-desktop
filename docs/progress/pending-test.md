# 待测试

## 画布性能九项优化 + 检查更新（本轮）

### 性能（①②③④⑤⑥⑦⑨⑩）

- 左栏列表行 `content-visibility` 估算高度修正为 56px（原 64 有 12% 偏差，滚动锚定会跳）
- 桌面版 WebView2 启用 GPU 光栅化与零拷贝合成（`--enable-gpu-rasterization --enable-zero-copy`，用户已手动设置环境变量时尊重用户值）
- 打开画布约 3 秒后自动后台预生成 256 小档预览（全局队列限流，不阻塞交互），左栏滚动不再边滚边生成替换
- 左栏列表滚动期间暂缓缩略图订阅触发的重渲染，停止滚动 160ms 后统一刷新
- 左栏「画布元素」列表窗口化：只挂载滚动窗口附近约 26 行（等高 56px + 6px 间距），节点再多 DOM 数量恒定；选中节点在窗口外时自动定位过去
- 连线组件 memo 化：拖动节点只重算涉及该节点的连线，其余连线跳过渲染
- 画布视口裁剪边距改为恒定 280px 屏幕边距（原固定世界边距在放大时渲染过多、缩小时过少）
- 底部工具栏与缩放控件 memo 化：所有回调改稳定引用，页面其它状态变化不再重渲染两个 dock
- 画布图片节点按渲染尺寸增加 768 中档预览（`@768`）：缩小画布查看整图时解码内存比 1536 档再降约 4 倍，就地生成、放大自动回退主档/原图

### 检查更新（方案 A）

- 设置弹窗顶部新增「关于」区块：显示当前版本 + 「检查更新」按钮；发现新版时显示版本号、前 4 条变更摘要和「前往下载」（打开 GitHub Releases 页，手动下载替换，不强制、不自动下载）
- 版本数据源改为本项目真实仓库的 GitHub Releases API（自动排除 prerelease，`desktop-latest` 滚动包不会误报）
- 每次启动按 24 小时节奏静默检查一次；有新版时首页顶栏与画布页顶栏的设置齿轮显示绿点
- 桌面版构建时把根目录 `VERSION` 注入前端（`NEXT_PUBLIC_APP_VERSION`），工作流与本地脚本同步；网页开发模式显示「开发版」且不弹更新提示
- 断网 / GitHub 限流时显示「检查失败」并可重试，不影响其它功能

## 左栏 40px 小图专用 256px 预览档（上轮）

- 预览缓存新增第二档：`@256` 后缀独立存取（主档仍为 1536px），`ensureImagePreview` 支持指定生成边长
- 画布元素列表的行缩略图优先用 256 小档：解码体积从 ~150-300KB/张降到 ~10-20KB/张，小一个量级；小档未就绪时回退主档，再回退原图
- 小档在「画布元素」页签打开时就地生成（走既有全局队列，最多并行 2 张，不阻塞 UI），恢复画布时的预览清理名单已包含小档，避免每次打开被误删重生成
- 改动：`lib/image-thumbnail.ts`、`services/image-storage.ts`、`canvas-side-panel.tsx`、`canvas-client-page.tsx`（清理名单）

## 左侧面板滚动流畅度（上轮）

- 画布元素/资产/提示词库三个页签的滚动条统一为细滚动条（此前画布元素页签是系统默认粗滚动条），并阻止滚到底后继续滚动穿透画布
- 列表行启用 `content-visibility: auto`：滚动到视口外的行完全跳过布局与绘制，几十个节点的长列表滚动不再随行数变卡
- 列表内图片全部改为懒加载 + 异步解码（`loading="lazy"` / `decoding="async"`），滚动进入视口才解码对应缩略图
- 改动集中在 `canvas-side-panel.tsx`，不涉及画布本体

## 画布拖拽/缩放卡顿与"刷新感"修复（上轮）

- 平移画布时的"刷新感"（周期性回跳）：手势期间任何 React 重渲染（任务轮询等）都会把画布 transform 打回旧值一帧；现在每次渲染后会重新套用最新手势 transform，拖动中不再瞬移
- 滚轮缩放卡顿：原来每个滚轮事件都触发整页 setState（全部节点重渲染）；现在缩放手势期间只直写 DOM（rAF 合帧），停手 140ms 后一次性提交，多张 4K 图下缩放明显更顺
- 缩放手势期间节点底部的反缩放面板（提示词面板等）通过 CSS 变量实时跟随，不再等提交后才回正
- 缩放未提交时立刻开始拖动画布、或点击"适应全部节点/聚焦节点"：手势结果会被正确衔接或让位，不会跳变
- 窗口失焦打断拖动时，已发生的位移会正常提交，不再出现回跳
- 节点四角拉伸：mousemove 按帧合并（rAF）后才更新节点尺寸，松手提交最终尺寸；整棵画布树不再跟随每次 mousemove 重渲染
- 移除页面级每秒时钟：加载中节点的计时改由节点自身本地秒表驱动，画布页不再每秒整页重渲染
- 内部改动集中在 `infinite-canvas.tsx`（live transform + 手势提交）、`canvas-node.tsx`（resize rAF 合并）、`canvas-client-page.tsx`（移除 canvasNow 时钟）

## 图片节点再次生成

- 提示词面板「生成」按钮与节点「重新生成」按钮均不再引用节点自身已生成的结果：即使连线或副本中存在同一张图，也会被过滤
- 「覆盖当前节点」模式：在原节点上全新重新生成（只使用提示词 + 上游连线参考）
- 「新建节点重新生成」模式（默认）：保留旧节点，在右侧新建节点用相同提示词全新生成（重摇结果）
- 需要基于旧图继续编辑（图生图）时，把另一张图连线到目标节点即可；全景图节点的自身参考行为保持不变

## 创造副本状态修复

- 右键「创造副本」和 Ctrl/Cmd+V 粘贴不再继承生成中的中间状态：副本不携带任务 ID、进度、耗时、错误信息等字段
- 生成中的节点被复制后，副本为「未开始生成」的干净状态（有图则显示原图，无图则待生成），不会与原节点共享任务、不会误显示加载中
- 副本保留原始输入与配置（提示词、模型、尺寸、连线参考关系）

## 工具栏「图片」挂参考

- 当某个节点的提示词对话框打开时，点击顶部工具栏「图片」：新图片节点自动创建在该节点左侧、连线挂为它的参考（与 @图片 相同的连线语义），并立即弹出文件选择
- 选择图片后直接进入新节点，原对话框保持打开，图片自动出现在「参考内容」里；取消选择时保留已连接的空节点，稍后可再上传
- 没有对话框打开时，工具栏「图片」行为不变（新建独立图片节点）

- 移除整个管理后台（admin）前端页面
- 移除云端同步：画布项目、我的素材、模型配置、渠道传参、工作流渠道不再同步到账号，全部只存浏览器本地（IndexedDB/localForage）
- 移除服务端素材库：/asset-library 页面、画布侧栏与素材选择弹窗的「素材库」标签、工具栏「素材库」按钮均已删除；「添加节点」菜单中改为「从我的素材选择」；本地素材的全部功能（增删改查、筛选、拖入画布）不受影响
