# 待测试

## 桌面版 exe（infinite-canvas-desktop.exe）

- 已通过 GitHub Actions 自动构建并本地冒烟验证：首页/画布页/JS 资源 200，Go API（health/settings/prompts）正常
- 独立窗口：exe 启动后打开原生应用窗口（Windows 自带 WebView2 渲染，无地址栏/标签页），不再是浏览器标签页；关闭窗口即退出程序；WebView2 运行时缺失时自动回退浏览器模式
- 广告清理：删除顶部 TokenDance 公告横幅（含 404 页）、首页两张带推广/返利链接的轮播图（保留产品功能展示图）
- 设置入口：顶栏新增齿轮按钮、画布页顶部新增齿轮按钮，均可打开「配置与用户偏好」（本地模型渠道 / API Key / 生成参数）；此前设置弹窗无任何手动入口
- 右键体验：应用内全局屏蔽浏览器原生右键菜单（文本输入框内保留，方便复制粘贴），画布自研右键菜单不再被浏览器菜单干扰
- exe 位置：仓库根目录 `infinite-canvas-desktop.exe`（约 69MB）；双击或「启动桌面版.bat」启动，自动打开浏览器
- 端口机制：默认每次启动由系统分配随机空闲端口（不会与游戏等固定端口程序冲突）；需要固定端口时设置环境变量 `CANVAS_DESKTOP_PORT`（如 36512）
- 云端构建：仓库 https://github.com/118coder/infinite-canvas-desktop ，push 到 main 自动构建；滚动发行包 `desktop-latest` 可随时从浏览器重新下载 exe
- 本地一键构建脚本：`构建桌面版.bat`（需要本机 Bun + Go 1.25+，脚本带环境自检与中文指引；构建时临时把 Next 的 `/api` 代理目录改名，构建后自动还原）
- 数据全部落在本机：SQLite 数据库存放在 exe 同目录的 `data/`，画布/素材在浏览器本地存储中，关闭 exe 即退出
- 路由调整：打开画布统一为 `/canvas?project=<id>`（原 `/canvas/<id>` 移除），列表与编辑器共用 /canvas 路由，普通部署与桌面版行为一致
- 注意：exe 未签名，Windows 首次运行可能提示 SmartScreen，选择"仍要运行"即可

## 数据工程导出/导入

- 设置弹窗新增「数据工程」区块：导出数据工程 / 导入数据工程
- 导出内容（zip）：全部画布项目、我的素材、应用配置（含本地渠道和 API Key）、本地 Agent Skill、生图/视频工作台历史，以及上述数据引用的全部本地图片和媒体文件
- 导入行为：按 id 合并画布与素材（同 id 覆盖、其余保留）；应用配置与本地 Skill 整体替换；工作台历史按条目合并；引用文件恢复到本地存储后画布图片、素材封面、历史结果可直接显示
- 在新电脑上：安装软件 → 打开顶部「设置 → 数据工程 → 导入数据工程」选择 zip → 恢复完成，无需重新配置渠道

## 图片节点再次生成

- 提示词面板「生成」按钮与节点「重新生成」按钮均不再引用节点自身已生成的结果：即使连线或副本中存在同一张图，也会被过滤
- 「覆盖当前节点」模式：在原节点上全新重新生成（只使用提示词 + 上游连线参考）
- 「新建节点重新生成」模式（默认）：保留旧节点，在右侧新建节点用相同提示词全新生成（重摇结果）
- 需要基于旧图继续编辑（图生图）时，把另一张图连线到目标节点即可；全景图节点的自身参考行为保持不变

## 创造副本状态修复

- 右键「创造副本」和 Ctrl/Cmd+V 粘贴不再继承生成中的中间状态：副本不携带任务 ID、进度、耗时、错误信息等字段
- 生成中的节点被复制后，副本为「未开始生成」的干净状态（有图则显示原图，无图则待生成），不会与原节点共享任务、不会误显示加载中
- 副本保留原始输入与配置（提示词、模型、尺寸、连线参考关系）

## 工具栏「图片」挂参考

- 当某个节点的提示词对话框打开时，点击顶部工具栏「图片」：新图片节点自动创建在该节点左侧、连线挂为它的参考（与 @图片 相同的连线语义），并立即弹出文件选择
- 选择图片后直接进入新节点，原对话框保持打开，图片自动出现在「参考内容」里；取消选择时保留已连接的空节点，稍后可再上传
- 没有对话框打开时，工具栏「图片」行为不变（新建独立图片节点）

## 连线自动整理

- 底部工具栏新增「整理布局」按钮，画布空白处右键菜单新增「整理节点布局」
- 整理逻辑：按连线拓扑分层（上游在左、下游在右），层内按重心法排序减少交叉，各列相对最高列垂直居中
- 组框连同组内成员、批量展开的子图作为一个整体参与排版；没有连线的孤立节点保持原位
- 整理后画布自动缩放到适应全部节点；支持撤销（Ctrl/Cmd+Z）

## 本地化改造（移除服务端功能）

- 移除登录/注册：登录页、TokenDance 回调页保留（外部 AI 渠道授权仍在）、顶栏登录入口、404 页登录按钮均已删除
- 移除整个管理后台（admin）前端页面
- 移除云端同步：画布项目、我的素材、模型配置、渠道传参、工作流渠道不再同步到账号，全部只存浏览器本地（IndexedDB/localForage）
- 移除服务端素材库：/asset-library 页面、画布侧栏与素材选择弹窗的「素材库」标签、工具栏「素材库」按钮均已删除；「添加节点」菜单中改为「从我的素材选择」；本地素材的全部功能（增删改查、筛选、拖入画布）不受影响
- AI 生成不受影响：本地渠道（API Key 存浏览器）直连 OpenAI 兼容接口的链路保持原样；图片/视频/音频工作台与画布生成的本地直连路径未改动
- 依赖账号的功能不再可用：云端渠道（channelMode=remote）、工作流任务执行（RunningHub/ComfyUI 需登录后端）、云端转存（S3/WebDAV 需登录）会在触发时提示需要登录，本地版默认不可见
- 「我的素材」右键菜单保留：编辑、复制文本/下载、删除；上一版新增的「添加到素材库」已随服务端素材库一起移除

## 画布右键菜单

- 节点右键菜单支持：打组、取消打组、创造副本、复制内容、保存到我的素材、下载、删除；菜单按选区生效，右键已选中的节点时对整个多选生效，右键未选中的节点时只对该节点生效
- 多选节点后右键“打组”，生成组框；拖拽组框时组内全部节点一起移动（含原有 Ctrl/Cmd+G 快捷键行为）
- 右键组框“取消打组”解散整组并删除组框；右键组内成员“取消打组”只把该成员移出组；支持 Ctrl/Cmd+Shift+G
- “创造副本”复制节点及与副本相关的连线：副本端点重映射到新节点，外部端点保持不变；副本整体偏移 36px 并自动选中；支持 Ctrl/Cmd+D
- 组框创造副本时组内成员一并复制，组关系保持
- 空白画布右键菜单：新建图片/视频/音频/文本（在右键位置创建）、上传文件、粘贴节点、全选节点、适应全部节点
- 右键节点不再误触节点拖动和打开提示词面板；节点上按下中键改为画布平移
- 缩放控件新增“适应全部节点”按钮，自动缩放并居中显示全部节点（无节点时回退重置视图）
- 删除节点后没有成员的空组自动清理；快捷键说明弹窗已补充新增快捷键

## 我的素材

- 素材卡片右键菜单：添加到素材库、编辑、复制文本/下载、删除（删除仍走确认弹窗）
- “添加到素材库”需要登录；本地 `blob:`/`data:` 图片和音视频会先上传为可公网访问地址再入库；入库成功后记录来源，重复添加会提示“已在素材库中”
- 素材详情抽屉新增“添加到素材库”按钮
