## 视觉连续性：零黑框、零刷新闪烁（本轮，需优先验证）

- **硬性要求**：缩小、放大、反复来回滚轮缩放、中键连续拖拽，画面都不允许出现刷新、闪白/闪黑、图片消失又出现，也不能出现无内容的纯色/黑色框
- 轻量态与完整态现在是同一个 `CanvasNode`：缩小态只跳过标题、组标题、四角拉伸柄、连线端点、信息条与底部面板，`NodeContent → ImageContent → <img>` 子树完全保留，切换时图片 DOM 不重建（早期的 `CanvasNodeTile` 双组件方案已删除）
- 手势期间冻结形态（`viewportStore.isGestureActive()` 时不更新 `lightweightRef`），只在手势结束的 commit 用 0.4 进入 / 0.55 退出的双阈值迟滞切换一次
- 图片 `src` 永不为空：档位未就绪时兜底 `content`，换档前 `new Image().decode()` 预解码，目标档位暂缺时保留上一张图
- 组节点缩小态透明不遮挡子节点，文本节点显示正文，配置/视频/音频显示标题
- 预览队列每 12ms 分批推进、并发 4、手势停摆，不被 `requestIdleCallback` 饿死
- 待人工验证：小画布与大画布都要试；缩小到适应全部、放大到 200%、来回滚轮缩放跨越 0.4/0.55 阈值来回多次、中键连续拖拽 5 秒；用 DevTools Performance 逐帧截图确认没有任何空白帧

## 画布拖拽/缩放卡顿与"刷新感"修复（上轮）

- 平移画布时的"刷新感"（周期性回跳）：手势期间任何 React 重渲染（任务轮询等）都会把画布 transform 打回旧值一帧；现在每次渲染后会重新套用最新手势 transform，拖动中不再瞬移
- 滚轮缩放卡顿：原来每个滚轮事件都触发整页 setState（全部节点重渲染）；现在缩放手势期间只直写 DOM（rAF 合帧），停手 140ms 后一次性提交，多张 4K 图下缩放明显更顺
- 缩放手势期间节点底部的反缩放面板（提示词面板等）通过 CSS 变量实时跟随，不再等提交后才回正
- 缩放未提交时立刻开始拖动画布、或点击"适应全部节点/聚焦节点"：手势结果会被正确衔接或让位，不会跳变
- 窗口失焦打断拖动时，已发生的位移会正常提交，不再出现回跳
- 节点四角拉伸：mousemove 按帧合并（rAF）后才更新节点尺寸，松手提交最终尺寸；整棵画布树不再跟随每次 mousemove 重渲染
- 移除页面级每秒时钟：加载中节点的计时改由节点自身本地秒表驱动，画布页不再每秒整页重渲染
- 内部改动集中在 `infinite-canvas.tsx`（live transform + 手势提交）、`canvas-node.tsx`（resize rAF 合并）、`canvas-client-page.tsx`（移除 canvasNow 时钟）

## 图片节点再次生成

- 提示词面板「生成」按钮与节点「重新生成」按钮均不再引用节点自身已生成的结果：即使连线或副本中存在同一张图，也会被过滤

- 「新建节点重新生成」模式（默认）：保留旧节点，在右侧新建节点用相同提示词全新生成（重摇结果）
- 需要基于旧图继续编辑（图生图）时，把另一张图连线到目标节点即可；全景图节点的自身参考行为保持不变

- 没有对话框打开时，工具栏「图片」行为不变（新建独立图片节点）

## 连线自动整理

- 底部工具栏新增「整理布局」按钮，画布空白处右键菜单新增「整理节点布局」
- 整理逻辑：按连线拓扑分层（上游在左、下游在右），层内按重心法排序减少交叉，各列相对最高列垂直居中
- 组框连同组内成员、批量展开的子图作为一个整体参与排版；没有连线的孤立节点保持原位
- 整理后画布自动缩放到适应全部节点；支持撤销（Ctrl/Cmd+Z）

## 本地化改造（移除服务端功能）

- 移除登录/注册：登录页、TokenDance 回调页保留（外部 AI 渠道授权仍在）、顶栏登录入口、404 页登录按钮均已删除
- 移除整个管理后台（admin）前端页面
- 移除云端同步：画布项目、我的素材、模型配置、渠道传参、工作流渠道不再同步到账号，全部只存浏览器本地（IndexedDB/localForage）
- 移除服务端素材库：/asset-library 页面、画布侧栏与素材选择弹窗的「素材库」标签、工具栏「素材库」按钮均已删除；「添加节点」菜单中改为「从我的素材选择」；本地素材的全部功能（增删改查、筛选、拖入画布）不受影响
- AI 生成不受影响：本地渠道（API Key 存浏览器）直连 OpenAI 兼容接口的链路保持原样；图片/视频/音频工作台与画布生成的本地直连路径未改动
- 依赖账号的功能不再可用：云端渠道（channelMode=remote）、工作流任务执行（RunningHub/ComfyUI 需登录后端）、云端转存（S3/WebDAV 需登录）会在触发时提示需要登录，本地版默认不可见
- 「我的素材」右键菜单保留：编辑、复制文本/下载、删除；上一版新增的「添加到素材库」已随服务端素材库一起移除

## 画布右键菜单

- 节点右键菜单支持：打组、取消打组、创造副本、复制内容、保存到我的素材、下载、删除；菜单按选区生效，右键已选中的节点时对整个多选生效，右键未选中的节点时只对该节点生效
- 多选节点后右键“打组”，生成组框；拖拽组框时组内全部节点一起移动（含原有 Ctrl/Cmd+G 快捷键行为）
- 右键组框“取消打组”解散整组并删除组框；右键组内成员“取消打组”只把该成员移出组；支持 Ctrl/Cmd+Shift+G
- “创造副本”复制节点及与副本相关的连线：副本端点重映射到新节点，外部端点保持不变；副本整体偏移 36px 并自动选中；支持 Ctrl/Cmd+D
- 组框创造副本时组内成员一并复制，组关系保持
- 空白画布右键菜单：新建图片/视频/音频/文本（在右键位置创建）、上传文件、粘贴节点、全选节点、适应全部节点
- 右键节点不再误触节点拖动和打开提示词面板；节点上按下中键改为画布平移
- 缩放控件新增“适应全部节点”按钮，自动缩放并居中显示全部节点（无节点时回退重置视图）
- 删除节点后没有成员的空组自动清理；快捷键说明弹窗已补充新增快捷键

## 我的素材

- 素材卡片右键菜单：添加到素材库、编辑、复制文本/下载、删除（删除仍走确认弹窗）
- “添加到素材库”需要登录；本地 `blob:`/`data:` 图片和音视频会先上传为可公网访问地址再入库；入库成功后记录来源，重复添加会提示“已在素材库中”
